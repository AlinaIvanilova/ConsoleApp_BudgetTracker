# Головна ціль проєкту

**Формат**: консольний застосунок\
**Мова**: чистий Ruby (БЕЗ Rails, БЕЗ Sinatra)\
**Мета**: навчитися працювати з логікою фінансових даних, архітектурою та збереженням інформації

## Головна ціль проєкту
### **Навчитися**:
- писати чистий та структурований Ruby-код
- працювати з класами та об'єктами
- розділяти відповідальність між файлами
- працювати з JSON
- створювати логіку обчислення балансу
- обробляти помилки користувача

## Функціонал (MVP — обов’язково)
###  1. Транзакція (Transaction)
Кожна транзакція має:
- id
- amount
- category
- type (income / expense)
- date
- created_at
### 2. Можливості програми
У консолі користувач може:
- Додати дохід
- Додати витрату
- Показати всі транзакції
- Показати поточний баланс
- Видалити транзакцію
- Зберегти транзакції у файл
- Завантажити транзакції з файлу
- Вийти з програми
### 3. Додаткові можливості (поглиблена логіка)
- Фільтр транзакцій по категорії
- Підрахунок витрат по категорії
- Показати витрати за певний місяць
- Перевірка коректності введених даних
- Обробка помилок
